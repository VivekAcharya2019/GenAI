# GenAI Learning Repository

This repository is a hands-on learning path for Generative AI, Python programming, and LLM application development. It follows a daily-study structure from beginner Python concepts to core LangChain, LangGraph, and RAG workflows up to Day 28.

## Overview

This repo is designed to help build practical understanding in the following areas:

- Python fundamentals and core programming logic
- Variables, strings, loops, collections, and functions
- Object-oriented programming (OOP)
- Modules, imports, and project structure
- Virtual environments and package management
- Prompt engineering and LLM usage basics
- Ollama for local model interaction
- LangChain and LangGraph fundamentals
- Pydantic models and validation
- Retrieval-Augmented Generation (RAG)
- Chunking strategies and document processing
- Vector similarity metrics and search concepts
- FAISS flat index and HNSW index basics

## Repository structure

The folders are organized by topic and day, covering the journey up to Day 28:

- Day_1 to Day_12: Python basics, variables, strings, loops, collections, functions, imports, and OOP fundamentals
- Day_13 to Day_15: OOP continuation, virtual environments, and advanced Python practices
- Day_16 to Day_19: Ollama, LangChain, and prompt engineering
- Day_20 to Day_25: Pydantic, LangGraph, and workflow-based model interaction
- Day_27 to Day_28: RAG foundations, chunking methods, vector search metrics, and FAISS indexing concepts

## Typical learning flow

1. Start with Python basics and problem-solving
2. Practice notebooks and scripts for each day
3. Move into LLM interaction and prompt design
4. Learn LangChain and LangGraph workflow patterns
5. Understand Pydantic and structured data modeling
6. Build RAG concepts using chunking, indexing, and retrieval
7. Explore vector similarity and FAISS-based retrieval

## Prerequisites

Before using this repo, make sure you have:

- Python installed
- Jupyter Notebook or VS Code with notebook support
- A virtual environment for project isolation
- Internet access for installing Python packages and model dependencies

## Getting started

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

Then open the relevant day folder and follow the notebooks in order.
